# SwiftTech Sales Performance Audit

## Project Overview
This project involves a comprehensive audit of sales data for SwiftTech Electronics. Using Python and Pandas, I performed data cleaning, handled categorical inconsistencies, and analyzed regional sales performance to drive business insights.

## Key Insights
* **Data Integrity:** Identified and corrected naming inconsistencies in regional data (e.g., 'north' vs 'North').
* **Revenue Drivers:** Identified Laptops as the primary revenue generator ($2,400).
* **Regional Analysis:** Found that the North region accounts for 50% of total order volume.

## Tools Used
* **Python** (Pandas, NumPy)
* **Matplotlib** (Visualization)
* **Jupyter Notebooks**
